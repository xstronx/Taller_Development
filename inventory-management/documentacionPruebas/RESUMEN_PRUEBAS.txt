## 🚀 CÓMO EJECUTAR LAS PRUEBAS

### Opción 1: PowerShell (Windows)
```powershell
# Ejecutar todas las pruebas
./run-tests.ps1 all

# Ejecutar solo unitarias
./run-tests.ps1 unit

# Generar reporte de cobertura
./run-tests.ps1 coverage

# Ver menú de opciones
./run-tests.ps1 help
```

### Opción 2: Bash (Linux/Mac)
```bash
# Ejecutar todas las pruebas
./run-tests.sh all

# Ejecutar solo unitarias
./run-tests.sh unit

# Generar reporte de cobertura
./run-tests.sh coverage

# Ver menú de opciones
./run-tests.sh help
```

### Opción 3: Maven Directo
```bash
# Todas las pruebas
mvn clean test

# Solo unitarias
mvn test -Dtest="*ServiceTest,*ValidatorTest,*UtilTest"

# Solo integración
mvn test -Dtest="*IntegrationTest"

# Con cobertura
mvn clean test jacoco:report
```

### Opción 4: JMeter
```bash
# Modo GUI
jmeter -t jmeter-stress-test.jmx

# Modo Headless
jmeter -n -t jmeter-stress-test.jmx -l results.jtl -j jmeter.log
```
