### El Cambio

Los controladores usan `@Autowired` en lugar de inyección por constructor.

**Antes**:
```java
private AuthController controller;

@BeforeEach
void setUp() {
    controller = new AuthController(authService);  // ❌ Error: constructor no existe
}
```

**Después**:
```java
@InjectMocks
private AuthController controller;

@BeforeEach
void setUp() {
    mockMvc = MockMvcBuilders.standaloneSetup(controller).build();  // ✅ Funciona
}
```
