## 🎓 LECCIONES CLAVE

### ❌ No usar @WebMvcTest para unitarias
```java
@WebMvcTest(MateriaPrimaController.class)  // ❌ Lento, requiere contexto
```

### ✅ Usar MockMvc.standaloneSetup()
```java
@ExtendWith(MockitoExtension.class)
private void setUp() {
    mockMvc = MockMvcBuilders.standaloneSetup(controller).build();  // ✅ Rápido
}
```
